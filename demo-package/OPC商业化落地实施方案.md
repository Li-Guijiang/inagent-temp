# OPC 一人小微团队商业化落地实施方案

## 1. 目标客户画像

江苏中小制造企业（约 50–500 人），没有专职数据团队，优先选择已有 MES/设备台账、但仍依赖人工质检、设备巡检或 Excel 汇总的企业。首批从 8 家调研企业中选择 2–3 家做样板。

## 2. 服务模式

- **轻量化三件套**：3 个技能包 + 操作工控制台，适合单车间快速试点。
- **全量五件套**：五个技能包 + 四大 Agent + 能耗看板，适合多产线推广。
- OPC 负责标准、配置、部署和月度复盘；企业提供设备/质量/能耗数据接口与业务负责人。

## 3. 建议定价

| 套餐 | 内容 | 建议价格 |
| --- | --- | --- |
| 轻量化 | 3 技能包 + 控制台 + 1 个数据源 | ¥9.9 万/年 |
| 全量互联 | 5 技能包 + 4 Agent + 3 个数据源 | ¥19.8 万/年 |
| 试点 | 样板车间、1 个月、指标基线与复盘 | 免费试用 1 个月，验收后转年费 |

## 4. 试点计划

1. 第 1 周：确认设备、批次、能耗字段，建立基线和权限。
2. 第 2 周：接入 1 条产线，跑通五个技能包与控制台。
3. 第 3 周：操作工试用，记录告警处置、质检工时和报表耗时。
4. 第 4 周：对照指标复盘，形成 ROI 报告和扩展报价。

## 5. 一人团队成本结构

产品/方案、部署、数据适配和客户成功由同一 OPC 负责人承担；重复性工作由技能包、模板和批量调度复用。第二个项目开始，主要新增成本为数据适配和现场培训，而不是重新开发完整系统。
