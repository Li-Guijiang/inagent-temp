# 设备点检标准知识库

> 版本：v1.0 ｜ 维护人：inAgent 设备点检 Skill
> 依据：江苏智能制造 8 家企业调研日志整理出的设备点检需求（天钧、贝斯特、禾派阁、聚晟视、樵弋、赫伽力、国投融合、富强）
> 说明：本表为 `analysis.py` 的判定依据。状态判定遵循“由内向外”原则——
> - 取值落在 `[正常下限, 正常上限]` → **正常**
> - 超出正常区但未突破 `[预警下限, 预警上限]`（即预警区间） → **预警（轻微）**
> - 超出预警区但未突破 `[紧急下限, 紧急上限]`（即严重区间） → **严重**
> - 超出 `[紧急下限, 紧急上限]` → **紧急**
> - 仅需单边限制的项（如温度只看上限）将不相关一侧填 `0`，该侧不参与判定。

## 判定规则说明

- 每台设备状态 = 该设备全部点检项中最严重的一级（正常 < 预警 < 严重 < 紧急）。
- “预警（轻微）”需在 24h 内复核；“严重”需当班处理；“紧急”需立即停机检修。
- 数值超限的 24h 累计次数（`over_count`）由 `data_fetch.py` 统计，供趋势参考。
