# 行业痛点汇总

## 使用场景

- 学生已完成若干企业的信息检索/风险研判/横向对比，希望上升到行业层面归纳共性痛点。
- 也可基于学生提供的行业资料、访谈记录或调研发现直接汇总痛点。

**前置输入（必须确认）**：调研的企业样本（企业名称清单，或已产出的调研信息卡/风险研判/对比结果），以及（可选）行业公开资料、访谈/问卷等一手材料。
**若缺失**：明确告知学生"请提供已调研企业名单或行业资料；若尚未开展企业调研，可以先用已检索到的企业信息进行分析"。

## 执行流程

1. **输入校验**：确认企业样本或行业材料；若样本为空，先引导学生完成至少一家企业信息检索。
2. **痛点汇总**：从企业样本与行业资料中归纳共性痛点，常用分析维度：
   - 技术与创新：核心技术短板、成果转化、研发人才。
   - 人才与用工：高技能人才缺口、招工难、人才流失。
   - 资金与融资：融资渠道、研发投入不足、账期压力。
   - 供应链：原材料波动、核心零部件依赖进口、供应链协同。
   - 市场与竞争：同质化竞争、订单获取、品牌出海。
   - 数字化与转型：数字化基础薄弱、数据孤岛、智能改造成本高、效益不清晰。
   - 政策与合规：政策获取渠道、认证合规、环保能耗要求。
3. **分级归类**：按"共性程度高/中/低"或"影响大/中/小"将痛点分级，并标注来源（哪个企业/哪份资料支持该痛点）。
4. **输出**：结构性《行业痛点清单》，供机会挖掘与报告引用。

## 输出

《行业痛点清单》：

```
【行业痛点清单】（江苏智能制造 · 调研时间：xxxx）
- 样本说明：调研企业 N 家（列出名称），资料范围：...

| 痛点编号 | 痛点主题 | 痛点描述 | 共性程度 | 影响程度 | 证据来源 | 相关企业 |
|---|---|---|---|---|---|---|
| P1 | ... | ... | 高 | 高 | 调研资料/企业A | ... |
| P2 | ... | ... | ... | ... | ... | ... |

【痛点评述】
1. 最突出的 2~3 项痛点及原因：...
2. 痛点之间的关联（如人才→研发→创新）：...
3. 与政策/行业趋势的呼应：...
4. 信息不足与待补充材料：...
```

- 每条痛点尽量给出证据来源；推断归纳处标注"归纳"。
- 避免编造行业数据；引用公开统计或政策时注明来源。
- 输出后衔接提示：可基于痛点清单继续做业务机会挖掘（`business-opportunity-mining`）。
