# 企业风险研判

## 使用场景

- 学生对**已选定**的目标企业进行风险体检。
- 用于对比分析、机会挖掘、报告撰写前的风险维度输入。

**前置输入（必须确认）**：目标企业名称（建议已通过 `enterprise-info-search` 取得基础信息；若未检索过，可先行检索）。
**若缺失或未选定目标企业**：明确告知学生"请先选定要研判的目标企业名称"，不得凭空猜测企业风险。

## 执行流程

1. **输入校验**：确认目标企业已选定；尽量复用《企业调研信息卡》作为基础数据。
2. **分维度研判**（公开信息 + 学生提供的资料）：
   - 经营风险：主营依赖度、订单/客户集中度、产能利用、市场竞争力、退市/注销预期。
   - 财务风险：负债率、现金流、应收账款、担保、以及可获取的财务报表信号。
   - 法律风险：诉讼、仲裁、被执行、合同纠纷、股权冻结。
   - 信用风险：经营异常名录、严重违法失信、行政处罚、海关/税务异常。
   - 供应链风险：原材料依赖、客户/供应商集中度、断供风险、进出口合规。
   - 创新与技术风险：研发投入、专利质量、核心技术替代与迭代风险。
3. **定级汇总**：按"高 / 中 / 低"三档给出每个维度风险等级，并给出**综合风险等级**与研判依据。
4. **输出**：整理《企业风险研判表》并附结论与建议。

## 输出

《企业风险研判表》：

```
【企业风险研判表】
- 企业名称 / 研判日期 / 数据来源与时效说明

| 风险维度 | 风险等级(高/中/低) | 主要风险点 | 证据/现象 | 建议核查渠道 |
|---|---|---|---|---|
| 经营风险 | ... | ... | ... | ... |
| 财务风险 | ... | ... | ... | ... |
| 法律风险 | ... | ... | ... | ... |
| 信用风险 | ... | ... | ... | ... |
| 供应链风险 | ... | ... | ... | ... |
| 创新与技术风险 | ... | ... | ... | ... |

- 综合风险等级：高 / 中 / 低（附一句话研判结论）
- 重点风险提示：1~3 条最优先关注的事项
- 信息不足项：明确列明缺失信息与建议获取渠道
```

- 必须区分"事实数据"与"分析推断"，推断项标注"推测"。
- 结论用于学习、研究、参考，重要决策前须提醒学生向权威渠道核实。
- 数据有时效性风险时（如运营异常、股权变更），提示学生复核最新状态。
