## 判定规则说明

- 每台设备状态 = 该设备全部工艺项中最严重的一级（正常 < 预警 < 严重 < 紧急）。
- 工艺参数优先关注"波动性/偏差"，超出工艺窗口即应校正。
- 数值超限的累计次数（`over_count`）由 `data_fetch.py` 统计，供工艺改进参考。
