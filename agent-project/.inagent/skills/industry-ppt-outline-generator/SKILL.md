# 行业PPT大纲生成器

## 使用场景

- 学生已完成企业信息检索/对比/痛点/机会等调研分析，需要将调研成果转化为行业总结性质的演示文稿；本技能产出**PPT大纲**（页级框架），不直接生成成品 PPT 页面。

**前置输入（必须确认）**：
- 调研分析成果：企业对比结论、行业痛点清单、机会清单、关键数据（至少其一；若有对比报告更佳）。
- PPT 主题与用途（可选）：如课程汇报、课题答辩、竞赛演讲，用于确定详略与风格。
**若缺失素材**：明确告知学生"生成PPT大纲前，请提供调研分析成果（对比结论/痛点清单/机会清单等）；若还没有，我可以先带你完成企业调研与行业分析"。

## 执行流程

1. **输入校验**：确认已有调研分析素材，确定PPT用途与篇幅（建议 15~25 页，可根据用途调整）。
2. **大纲设计**：围绕"背景-现状-对比-痛点-机会-结论"的逻辑主线组织页面：
   - 封面页：标题、汇报人、时间。
   - 目录页：章节导航。
   - 报告概述：背景、目的、调研方法与范围。
   - 企业样本与数据基础：被调研企业一览、数据来源。
   - 多企业对比：规模/技术/市场/风险对比（图表建议）。
   - 行业痛点汇总：分级呈现。
   - 业务机会挖掘：机会与建议。
   - 结论与展望：核心结论、研究建议。
   - 结尾页：致谢 / 参考资料。
3. **逐页编写要点**：每页给出页码、标题、页面要点与可视化建议（表格/柱状图/雷达图等）。
4. **复核**：页数与逻辑与调研成果对应，不遗漏关键结论。
5. **输出大纲**：Markdown 大纲。

## 输出

《行业总结PPT大纲》（Markdown）：

```
【行业总结PPT大纲】（标题：江苏xx行业智能制造调研总结 · 共 xx 页）
（汇报用途：课程汇报/课题答辩/竞赛演讲——据此确定篇幅与详略）

1. 封面页
   - 标题、副标题、汇报人/小组、日期
2. 目录页
   - 01 报告概述 / 02 调研方法与样本 / 03 企业对比分析 / 04 行业痛点 / 05 业务机会 / 06 结论与建议
3. 报告概述（2页）
   - P3 调研背景与目的：...
   - P4 调研范围与方法：...（建议配流程图）
4. 调研方法与样本（1~2页）
   - P5 被调研企业一览表：企业A/B/C ... 数据来源说明
5. 企业对比分析（5~7页）
   - P6 规模与经营对比（建议柱状图）...
   - P7 技术与创新对比（建议雷达图）...
   - P8 市场与客户对比（表格）...
   - P9 风险对比（建议红黄绿灯表）...
   - P10 对比小结：位次与发现
6. 行业痛点汇总（3~4页）
   - P11 痛点总览（分级清单）...
   - P12 重点痛点详解：P1/P2 及佐证数据 ...
   - P13 痛点之间的关联 ...
7. 业务机会挖掘（3~4页）
   - P14 机会清单总览 ...
   - P15 高优先级机会详解 ...
   - P16 落地路径建议（流程图）...
8. 结论与展望（2~3页）
   - P17 核心结论：3~5 条
   - P18 研究局限与后续计划
9. 结尾页
   - 致谢页 / 参考资料与来源
```

- 大纲交付后，**必须提示学生**："PPT大纲已生成。请你根据大纲逐页完善PPT内容：填充每页要点文字、图表与案例数据，并标注信息来源；如需我协助扩写某一页的内容，可以直接把页码告诉我。"
- 不得夸大调研范围与数据；图表建议标注为"建议"，由学生依据实际数据制作。
