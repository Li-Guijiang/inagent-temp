# 业务机会挖掘

## 使用场景

- 学生已有企业信息卡/风险研判/对比结论/行业痛点清单，希望从调研中发现业务机会（如新建业务、产品方向、市场切入、合作模式、服务方案等）。

**前置输入（必须确认）**：
- 机会挖掘的对象与范围：面向某家企业/某几家企业，还是面向服务这些企业的第三方（方案商、服务商、供应商）。
- 基础材料：企业信息卡、风险研判、对比结论或行业痛点清单（至少提供其一）。
**若缺失**：明确告知学生"请先告诉我机会挖掘的对象（某家企业或某类企业），并提供已调研的基础材料（信息卡/痛点清单）；若还没有，我可以先带你完成信息检索"。

## 执行流程

1. **输入校验**：确认对象与基础材料齐备。
2. **短板-痛点映射**：将企业/行业短板与痛点清单逐条对应，形成"需求点"列表。
   - 例如：企业数字化基础薄弱 → 智能改造/数字化服务需求；人才缺口 → 培训/招聘服务需求；设备老旧 → 设备更新与绿色改造需求。
3. **机会生成**：为每个需求点匹配可行的机会方向，评估：
   - 机会描述（做什么、服务谁）。
   - 匹配主体（哪家企业/哪类企业受益，或谁可承接该机会）。
   - 可行性（技术、资金、资源是否能支撑）。
   - 优先级（综合考虑需求强度、市场规模、实施难度）。
4. **输出**：结构化《业务机会清单》。

## 输出

《业务机会清单》：

```
【业务机会清单】
- 分析对象：xxx企业 / xx类企业 / 服务商
- 依据材料：调研信息卡 / 风险研判 / 对比结论 / 行业痛点清单（注明）

| 机会编号 | 机会方向 | 对应痛点/短板 | 机会描述 | 匹配主体 | 可行性 | 优先级(高/中/低) | 启动建议 |
|---|---|---|---|---|---|---|---|
| O1 | ... | P1 | ... | ... | ... | ... | ... |

【机会评述】
1. 最具价值的前 3 个机会：...
2. 机会与地方政策/产业趋势的契合点：...
3. 落地第一步建议：...
4. 局限性说明（信息不足、假设前提等）：...
```

- 机会基于调研证据推导，不得虚构市场数据；涉及市场规模等数据时注明来源或标注"估算"。
- 输出后衔接提示：可进入成果生成环节（调研日志/对比报告/PPT大纲/背景材料）。
