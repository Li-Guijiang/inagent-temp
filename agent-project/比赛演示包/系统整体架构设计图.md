## 三、关键设计说明

| 层次 | 组件 | 说明 | 对应命题能力 |
| --- | --- | --- | --- |
| 应用层 | 四大 Agent + 能耗看板 | 面向工厂操作工的极简入口，隐藏技术细节 | 多 Agent 专家团、低门槛 |
| 能力层 | 五大技能包 | 通用目录结构 + "标准知识库即差异"，换表即换业务 | 垂直产业专属技能 |
| 数据层 | MCP 数据服务 + SQLite | 动态供数 + 历史入库，非死数据 | 搭建产业 MCP 服务、打通多源数据 |
| 技术底座 | inAgent 工作台 | 本地执行、单机部署、零订阅 | 本地执行、轻量化低成本 |

## 四、三类核心数据流

1. **实时数据流（动态）**：`产线/MCP服务 → data_fetch.py(--source mcp) → analysis.py → 日报/告警/台账`
   - 每次运行数值动态变化，自动入库，可经 `/api/sources`、`/api/history/<src>` 查证。
2. **操作工交互流（闭环）**：`操作工控制台 → Agent 接口（质检上报/工艺解析/报表/告警）→ 业务动作`
   - A1 上报落盘、A2 解析工艺卡、A3 汇总报表（可下载 Excel）、A4 告警处置。
3. **告警通知流（扩展）**：`analysis.py 判级 → 分级告警文件 → （预留）企业微信 MCP 推送`
   - 严重/紧急告警可通过 `report_gen.py::_send_wecom_alert` 接入真实推送。

## 五、与命题"功能闭环"核对（≥3 项 inAgent 能力）

| inAgent 能力 | 本方案落地 |
| --- | --- |
| ✅ Skill 技能包 | 5 个技能包（SKILL.md+scripts+templates+docs 规范） |
| ✅ 多 Agent 专家团 | 四大 Agent（A1-A4）同一控制台协同 |
| ✅ MCP 连接器 | app.py 动态数据 MCP 服务（端口5000）＋ 预留真实 MCP 接入点 |
| ✅ 定时/批量调度 | run_demo.bat 一键批量调度 5 条流水线（对应 inAgent 批量任务） |

> 已满足"至少整合 3 项及以上 inAgent 能力"的硬性要求，且非碎片化单一功能。

## 六、部署模式（轻量化）

| 模式 | 说明 | 适用 |
| --- | --- | --- |
| 本地单机（默认） | inAgent 桌面工作台 + Python 脚本，数据不出厂 | 中小工厂、数据敏感场景 |
| 车间一体机 | 预装一体机部署，开箱即用 | 预算有限、怕折腾的客户 |
| 云端/边缘（预留） | 数据源替换为云端 MCP / 边缘网关 | 集团、园区多场地 |
