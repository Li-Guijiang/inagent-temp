> - 仅需单边限制的项（如漏检率只看上限）不相关一侧填 `0`。

## 判定规则说明

- 每台设备状态 = 该设备全部巡检项中最严重的一级（正常 < 预警 < 严重 < 紧急）。
- 漏检率类指标上升 0.5% 即触发预警，体现"漏检不可容忍"原则。
- 数值超限的 24h/批次累计次数（`over_count`）由 `data_fetch.py` 统计。
