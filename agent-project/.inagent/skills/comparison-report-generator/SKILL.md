# 企业对比报告生成器

## 使用场景

- 学生已完成企业信息检索、风险研判、横向对比（或至少拥有可用的企业信息卡与对比矩阵），希望产出一份正式、完整的企业对比分析报告。

**前置输入（必须确认）**：
- **已选定对比企业**（报告覆盖的企业名单，≥2 家）。
- 基础材料：各企业《调研信息卡》、对比矩阵（推荐）、风险研判结论、（可选）行业痛点与机会清单。
**若未选定对比企业**：明确告知学生"生成对比报告前，请先选定要纳入报告的对比企业名单"，确认后再生成。
**若缺少基础材料**：提示学生先进行信息检索/横向对比，或说明报告数据将以现有已检索信息为准。

## 执行流程

1. **输入校验**：确认对比企业名单与基础材料；否则先补齐。
2. **素材整合**：汇总各企业信息卡、对比矩阵、风险研判、痛点与机会结论，形成报告数据底稿。
3. **报告撰写**：按下列规范组织章节，数据与结论保持一致，引用来源。
4. **质量复查**：数据一致性（报告数字与信息卡一致）、结论闭环（问题→风险→建议链条完整）、无空泛表述。
5. **输出**：完整《企业对比分析报告》。

## 输出

《企业对比分析报告》（Markdown 文档结构）：

```
【企业对比分析报告】
标题：xx地区/xx行业 企业对比分析报告（调研时间：xxxx-xx-xx）
1. 报告概述
   - 调研背景与目的 / 调研范围与方法 / 数据来源与时效说明
2. 调研企业概况（每家一表）
   - 企业A / 企业B / 企业C：基本信息、经营、技术、资质
3. 对比分析（核心章节）
   3.1 规模与经营对比（表格）
   3.2 技术与创新对比（表格）
   3.3 市场与客户对比（表格）
   3.4 风险对比（表格，引用风险研判结论）
   3.5 汇总访谈/调研发现
4. 综合结论
   - 综合位次 / 各自优势与短板 / 关键发现
5. 问题与业务机会建议
   - 行业痛点对应（引用痛点清单） / 业务机会建议（引用机会清单） / 对研究/选型/实践的建议
6. 附录
   - 企业调研信息卡 / 风险研判表 / 资料来源与参考清单
```

- 报告中的数字、结论必须与前期调研成果一致。
- 明确标注信息不足项与待核实项，不虚构对比数据。
