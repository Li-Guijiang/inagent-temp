# 调研日志生成器

## 使用场景

- 学生已完成（或正在进行）某家企业的资料收集、访谈、参观等活动，需要形成规范的调研日志，用于课程作业、过程记录、报告素材沉淀。

**前置输入（必须确认）**：该企业的**基础资料**（学生上传的文本/文档，如企业简介、营业执照/工商信息、访谈记录、参观笔记、产品资料等，至少提供一份）。
**若缺失**：明确告知学生"生成调研日志前，请先上传该企业的调研基础资料（如企业简介、访谈记录、参观笔记等，文本或文档均可）"，收到后再生成。

## 执行流程

1. **输入校验**：确认基础资料已上传；资料若为空，先请求上传，不生成空泛日志。
2. **内容抽取**：从资料中提取调研对象、时间、方式、参与人员、企业概况、关键发现、问题与风险、后续计划等要素。
3. **结构化组织**：按模板把抽取内容组织成完整日志；对材料未提供的信息如实留空或标注"待补充"。
4. **质量复核**：检查时间/主体一致性、事实与推断分离、无资料支撑的表述不臆写。
5. **输出**：结构化调研日志（可直接用于作业/报告素材）。

## 输出

《调研日志》（Markdown 文档）：

```
【企业调研日志】
一、调研基本信息
- 调研企业：xxx（统一社会信用代码：xx）
- 调研时间：xxxx-xx-xx / 调研方式：实地参观/访谈/资料调研
- 调研人员：xxx / 记录人：xxx
二、企业概况
- 主营业务、规模、技术与资质概况（来源于企业基础资料）
三、调研过程记录
- 时间段/环节：接待方、访谈对象、主要内容、关键信息 ...
四、主要发现
- 经营亮点 / 技术亮点 / 管理亮点 / 数字化现状 ...
五、存在的问题与风险
- 问题描述 + 依据（资料页码或访谈原话/纪要）
六、下一步调研计划
- 待补充资料、待确认问题、后续访谈安排 ...
七、附注
- 资料来源清单 / 待核实项 / 记录人签名栏
```

- 日志是对企业基础资料的忠实整理，事实与推断分开标注。
- 缺失信息如实标注"待补充（建议获取渠道：xx）"，不编造详情。
