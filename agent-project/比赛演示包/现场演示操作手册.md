> **配套文件**：run_demo.bat（一键启动）、stop_demo.bat（停止）、install_deps.bat（装依赖）、check_env.py（环境自检）

## 一、赛前准备（比赛前一天，务必完成）

### 1.1 电脑要求
| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 |
| Python | 3.6+（推荐 3.10~3.12） |
| 依赖 | flask、openpyxl |
| 浏览器 | Chrome / Edge 均可 |
| 网络 | **不需要**（全部本地运行，数据出货不出厂） |

### 1.2 三步准备流程
1. **解压**：把「命题188智能制造比赛演示包.zip」解压到**英文路径**，例如 `D:\demo` 或 `C:\competition188\`（避免中文目录名带来的历史兼容问题；当前工作目录路径含中文也可用，但建议英文路径最稳）。
2. **装依赖**：双击 `install_deps.bat`，等待其自动安装 flask 与 openpyxl（使用清华镜像）。
3. **干跑一遍**：双击 `run_demo.bat`，确认 5 条流水线全部通过、四大 Agent 验证通过、浏览器自动打开 `http://127.0.0.1:8848`。

> 若 `run_demo.bat` 提示 `[ERROR] Environment check failed`，说明依赖未装全 → 重新双击 `install_deps.bat`。

### 2.1 开场启动（1 分钟）
1. 双击 `run_demo.bat`。
2. 等待约 40~60 秒，窗口依次显示：
   - `[0/6]` 环境自检 `ALL CHECKS PASSED`

## 三、防"打不开"预案（遇到问题照着做）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 提示 `python 不是内部或外部命令` | 电脑没装 Python 或没加 PATH | 装 Python 3.6+（安装时勾选 Add to PATH），或双击 install_deps.bat 看其提示 |
| 提示 `[ERROR] Environment check failed` | flask/openpyxl 缺失 | 双击 `install_deps.bat` |
| 端口 5000/8848 被占用（提示地址被占用） | 上次演示未完全退出 | 双击 `stop_demo.bat` 后重跑 |
| 四个黑窗口弹出一闪而过 | 流水线某步报错 | 重跑 run_demo.bat，观察窗口内 `[ERROR]` 哪一步；把窗口截图用于排查 |
| 中文变成乱码（∂’∂•∫æ∂ß） | 旧版 bat 编码问题 | **已修复**：新 run_demo.bat 是英文脚本 + 强制 UTF-8，不会再有此问题 |
| 浏览器没自动打开 | 极少环境差异 | 手动在浏览器地址栏输入 `http://127.0.0.1:8848` |
| 现场电脑无法联网 | 无影响 | 演示**完全离线**运行，不需要网络 |
| 演示中途需停止 | — | 双击 `stop_demo.bat`（结束 5000/8848 端口进程） |

## 四、故障排查（进阶）

### 4.1 查看日志
所有脚本输出统一记录到 `演示包\logs\` 目录：
- `mcp_service.log`：动态数据服务日志
- `pipeline.log`：5 条流水线日志（可从中找 `[ERROR]`）
- `console.log`：操作工控制台日志

### 4.2 数据哪里来
- 动态数据服务（端口 5000）每次生成动态采样并自动写入 `live_data\plant_live.db`
- 访问 `http://127.0.0.1:5000/api/sources` 可看到各数据源采样统计（动态数据库证明）

### 4.3 必备文件清单（演示包根目录）
```
run_demo.bat        一键启动（入口）
stop_demo.bat       停止服务
install_deps.bat    一键装依赖
check_env.py       环境自检
app.py              动态数据服务（端口5000）
live_data\          动态数据库
skills\             5 个技能包 + 操作工控制台
*.md                说明文档 + 调研/指标/OPC/架构材料
```
