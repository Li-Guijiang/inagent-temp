# 项目背景材料生成器

## 使用场景

- 学生正在进行课程项目、毕业设计、竞赛或课题研究，需要一份规范的"项目调研背景材料"用于立项、开题或项目申报。

**前置输入（必须确认）**：
- 项目主题（做什么研究/项目，例如"江苏装备制造企业数字化转型现状调研"）。
- 调研范围（地域、行业、企业样本偏好）。
- 可选的已有调研素材：企业信息卡/行业痛点/机会清单（用于充实背景），未提供时可用行业层面公开资料生成，但需标明待补充项。
**若主题缺失**：明确告知学生"请先告诉我你的项目主题（研究什么）和调研范围（行业/地区/企业），我才能生成对应的背景材料"。

## 执行流程

1. **输入校验**：确认项目主题、调研范围；无则先索取。
2. **背景素材组织**：围绕以下内容组织（结合已有调研成果与可核实的行业公开信息）：
   - 宏观背景：国家与江苏智能制造相关政策导向（如制造强国、智能制造相关政策、江苏省制造业高质量发展方向）。
   - 行业背景：相关细分行业的发展现状与趋势（仅使用可核实的公开信息，注明来源）。
   - 问题背景：基于已有痛点/调研发现提炼的"为什么要做这个项目"。
   - 研究意义与目标：理论/实践意义、项目目标。
   - 调研范围与思路：地域、行业、对象、方法（资料调研+企业调研+访谈等）。
   - 预期成果：报告、数据表、PPT、论文/作业等。
   - 进度安排框架（如适用）。
3. **风险提示**：政策表述与行业数据必须注明来源或标注"以权威发布为准"。
4. **输出**：结构化《项目调研背景材料》。

## 输出

《项目调研背景材料》（Markdown 文档）：

```
【项目调研背景材料】
1. 项目基本信息
   - 项目/课题名称、参与人、日期
2. 项目背景
   2.1 宏观政策背景（国家层面 / 江苏省层面；注明来源）
   2.2 行业发展背景（细分行业现状与趋势；注明来源）
   2.3 选题背景与问题提出（结合已有调研发现/痛点清单）
3. 研究意义
   - 理论意义 / 实践（课程、就业、产业）意义
4. 研究目标与内容
   - 总目标 / 具体研究内容（细分到各调研模块）
5. 调研范围与路线
   - 调研对象（企业样本）、地域范围、调研方法（资料/问卷/访谈/实地）、技术路线
6. 预期成果
   - 交付物清单（调研日志、对比报告、PPT大纲、研究报告等）
7. 进度计划（阶段/时间/任务/产出）
8. 参考资料与待补充信息
```

- 政策、统计类信息只使用可核实公开来源并注明出处；无把握处标注"待核实"。
- 材料面向学习/研究场景，重要使用前提示学生以权威渠道复核政策与数据。
