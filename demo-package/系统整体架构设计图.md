## 分层职责

- 数据源层：企业真实业务数据或演示数据。
- MCP 服务层：统一鉴权、字段和错误合同，屏蔽 MES/PLC/能源系统差异。
- 技能包能力层：采集、阈值分析、报告和告警产物。
- Agent 应用层：以操作工动作组织能力，不暴露实现细节。
- 操作工控制台：展示结果、接收上报、下载报表并留下审计记录。
