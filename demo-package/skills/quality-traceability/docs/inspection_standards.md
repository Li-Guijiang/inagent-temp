## 判定规则说明

- 每台设备状态 = 该设备全部追溯项中最严重的一级（正常 < 预警 < 严重 < 紧急）。
- 追溯类指标以"覆盖率/关联率/完整率/入库率"为主，低于阈值即存在质量追溯断链风险。
- 数值超限的累计次数（`over_count`）由 `data_fetch.py` 统计，供溯源体系改进参考。
