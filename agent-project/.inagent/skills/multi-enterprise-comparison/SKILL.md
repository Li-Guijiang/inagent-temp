# 多企业横向对比

## 使用场景

- 学生对选定的一组江苏制造企业做横向对比，用于选型、同业分析、竞争格局研究等。
- 前置依赖：建议相关企业已通过 `enterprise-info-search` 检索，形成可对比的数据基础。

**前置输入（必须确认）**：对比企业名单（**至少 2 家**，最好提供企业全称，例如：企业A、企业B、企业C）。
**若名单缺失或不足 2 家**：明确告知学生"请提供要对比的企业名单（至少 2 家，并用逗号或换行分隔）"。

## 执行流程

1. **输入校验**：确认名单 ≥2 家且名称无歧义；对名单中未检索过的企业，提示学生是否需要先补充信息检索。
2. **维度对齐**：统一各企业《调研信息卡》的数据口径（同一时间点、同一统计口径），无法对齐处标注差异。
3. **横向对比**（如适用维度差异，可调整）：
   - 规模维度：注册资本、员工人数、营收/产值、资产体量。
   - 经营维度：主营结构、业务聚焦度、增长态势。
   - 技术维度：专利数量与结构、研发强度、核心技术方向、资质等级。
   - 市场维度：市场定位、客户结构、区域分布、出口情况。
   - 风险维度：综合风险等级与主要风险点（复用 `enterprise-risk-assessment` 结论）。
   - 数字化/智能制造维度：智能工厂认定、数字化应用水平（如有数据）。
4. **汇总结论**：提炼各家优劣势、竞争位次、对比发现与选型/研究建议。
5. **输出**：对比矩阵 + 分析结论。

## 输出

《企业对比矩阵》与《对比分析结论》：

```
【企业对比矩阵】

| 对比维度 | 企业A | 企业B | 企业C |
|---|---|---|---|
| 成立时间 / 注册资本 | | | |
| 员工 / 营收规模 | | | |
| 主营与细分领域 | | | |
| 技术与专利水平 | | | |
| 资质与荣誉 | | | |
| 市场与客户 | | | |
| 综合风险等级 | | | |
| 数字化/智能制造水平 | | | |

【对比分析结论】
1. 各自优势：...
2. 各自短板：...
3. 综合位次与原因：...
4. 研究/选型建议：...
5. 数据口径说明与待补信息：...
```

- 缺失数据如实标"暂无数据"，不得为填表而估算。
- 对比结论面向学习与研究场景输出；涉及商业决策时提示学生核实权威数据。
