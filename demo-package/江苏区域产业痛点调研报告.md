# 江苏区域产业痛点调研报告

## 一、调研方法

基于 8 家江苏本土制造企业的调研日志，按设备、质量、工艺、数据、能耗和追溯六类问题归并。每条痛点保留企业来源、现场表现和可落地的技能包对应关系。

## 三、痛点分级

### P1：直接影响交付和质量

- 设备停机没有提前预警，故障后才人工处理。
- 关键焊接、视觉检测仍依赖少数熟练工。
- 批次信息分散，异常发生后无法快速还原责任链。

### P2：直接影响管理效率

- 生产、质量、设备和能耗数据各自留在 Excel 或独立系统。
- 日报、告警、汇总报表重复人工制作。
- 工艺知识没有结构化沉淀，新人上手周期长。

### P3：影响规模复制

- 不同企业字段、阈值和班次定义不一致。
- 缺少可量化的上线前后指标，难以形成采购依据。
- OPC 小团队需要标准化部署、培训和复盘模板。

## 四、场景—能力对应关系

五大技能包覆盖设备点检、质量巡检、能耗分析、工艺优化和质量追溯；四大 Agent 将其中高频动作封装为质检上报、工艺解析、生产报表和设备告警。优先落地路径为：**设备告警 → 质检上报 → 工艺解析 → 生产报表 → 能耗和追溯扩展**。
