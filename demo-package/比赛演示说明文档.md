## 一、作品概述

本作品基于江苏智能制造 8 家企业的实地调研，针对调研中暴露的**共性产业痛点**（质检依赖人工、工艺知识缺失、数据孤岛、设备运维短板、能耗与追溯管理薄弱），设计了一套 **"五个技能包 + 四大 Agent"** 的产业级智能制造解决方案：

- **底层**：5 个可独立运行、可扩展对接的技能包（设备点检、质量巡检、能耗分析、工艺优化、质量追溯），每个包均为"数据采集 → 阈值分析 → 报告生成"的可复现流水线。
- **上层**：面向**工厂操作工**的极简交互控制台，隐藏全部技术细节，仅保留 **4 个企业常用 Agent 入口** + 1 个能耗看板。

### 四大 Agent 一览

| Agent 编号 | 名称 | 对应入口 | 数据来源 | 定位 |
| --- | --- | --- | --- | --- |
| **A1** | 智能质检 Agent | 质检上报 | quality-inspection 技能包 | 质检结果上报、质检总览 |
| **A2** | 工艺知识 Agent | 工艺解析 | 内置工艺知识提取引擎 | 工艺文档智能解析、参数结构化 |
| **A3** | 产线数据 Agent | 生产报表 | 5 个技能包汇总 | 生产综合报表自动生成（含 Excel） |
| **A4** | 设备运维 Agent | 设备告警 | equipment-inspection 技能包 | 设备状态监控与异常告警 |

> 其余 2 个技能包（能耗分析、质量追溯）的数据已汇入 A3 生产报表，能耗看板作为**车间看板**独立保留在首页。

## 二、四大 Agent 功能详解

### A1 智能质检 Agent（质检上报）

**功能**
- 查看今日质检总览：正常 / 预警 / 严重 / 紧急 巡检项统计
- 操作工按工位、批次提交质检结果（合格 / 待复检 / 不合格）
- 上报记录自动落盘保存，累计今日上报条数与历史记录

**对应调研痛点**
- 贝斯特精密件人工抽检漏检风险
- 天钧电池箱体焊接质检难
- 樵弋 AOI 崩边漏检、聚晟视/禾派阁视觉检测误检漏检

**操作步骤**
1. 首页点击「📋 质检上报」
2. 填写工位/产线、批次号、选择班次与质检结果
3. 点击「提交上报」，页面提示"✅ 上报成功"并更新今日上报条数

### A2 工艺知识 Agent（工艺解析）

**功能**
- 粘贴或载入工艺文档，自动识别 `参数名：数值 单位` 与 `参数名 范围a~b` 两类格式
- 输出结构化参数卡片（参数名、数值、单位、建议区间）
- 一键载入示例工艺文档演示

**对应调研痛点**
- 天钧工艺参数分散、版本迭代快、知识难沉淀
- 贝斯特 CAD/CAM/CAE 仿真经验依赖老工程师

**操作步骤**
1. 首页点击「📑 工艺解析」
2. 点击「载入示例」或粘贴自有工艺文档
3. 点击「开始解析」，页面展示识别出的参数卡片
4. 可复制解析结果用于后续工艺知识库沉淀

### A3 产线数据 Agent（生产报表）

**功能**
- 一键汇总 5 个技能包（点检/质检/能耗/工艺/追溯）状态
- 展示各模块 正常/预警/严重/紧急 统计表与告警数
- 自动生成并下载 Excel 生产综合报表（`production_report_*.xlsx`）

**对应调研痛点**
- 生产、质检、设备数据分散（数据孤岛 P5）
- 缺少统一产线数据监控与自动报表

**操作步骤**
1. 首页点击「📊 生产报表」
2. 点击「一键生成报表」，页面展示五大模块统计表
3. 点击「⬇ 下载 Excel 报表」获取汇总文件

### A4 设备运维 Agent（设备告警）

**功能**
- 设备状态总览：运行正常台数、预警/严重/紧急告警数
- 逐条展示告警详情（设备、参数、当前值、正常范围、处置建议）
- 严重/紧急告警置顶，便于优先处理

**对应调研痛点**
- 贝斯特五轴/珩磨停机直接影响头部客户订单交付
- 天钧焊接设备超温易致焊缝缺陷
- 赫伽力 AGV/机器人续航与健康度

**操作步骤**
1. 首页点击「🔔 设备告警」
2. 阅读正常设备台数与告警列表
3. 按"急→重→轻"顺序处理，处置建议见每条告警底部

### 车间看板：能耗看板（💡）

**功能**
- 能耗单元状态总览与逐台能耗卡片展示
- 异常能耗单元以红/黄色高亮标注

## 四、企业落地价值

### 4.1 直接价值（针对 8 家调研样本企业）

| 价值维度 | 落地对象 | 具体收益 |
| --- | --- | --- |
| **降本** | 贝斯特、天钧 | 设备故障预警前置，减少突发停机导致的订单交付损失；能耗异常告警降低电费与气耗 |
| **提质** | 天钧、樵弋、聚晟视、禾派阁 | 质检数字化替代人工目检/抽检，提升一致性；工艺参数结构化沉淀，缩短新人上手周期 |
| **增效** | 赫伽力、富强 | 生产报表一键生成，减少人工统计；告警分级使处置更有序，提升多项目交付效率 |
| **安全可溯** | 国投融合、富强制售 | 质量追溯体系监控断链风险，支撑"一物一码、全程可溯"的合规要求 |

### 4.2 行业共性价值（面向江苏智能制造产业）

1. **低门槛落地**：操作工视角极简界面，无需 IT/算法人员即可日常使用；
2. **可复制推广**：5 个技能包"换标准表即换业务"，可快速适配江苏 16 大先进制造集群下的不同企业；
3. **渐进式智能化**：当前为边缘规则判定，预留真实数据 MCP、企业微信告警接入点，可平滑演进为 AI 大模型驱动的智能体；
4. **与政策契合**：贴合江苏"智改数转网联"与智能车间建设方向，能耗/追溯指标与绿色制造、质量强国要求对齐（引用政策前建议以官方文件核实）。

### 4.3 创新点
- **"技能包沉淀能力 + Agent 面向业务"双层次架构**：同一数据分析能力既服务技术人员（技能包）又被封装为操作工可用的业务 Agent；
- **4 个 Agent 全部真实可运行**：非概念演示，每个 Agent 均含可调用接口与验证脚本；
- **统一报告/告警/台账三重产物**：每次运行产出 Markdown 日报、分级告警文件与 Excel 台账，可追溯可审计。

## 五、部署与扩展

### 5.1 数据如何更新
- 技能包数据随流水线重跑自动更新（`run_demo.bat` 已内置）；
- 生产环境将各包 `scripts/data_fetch.py::_fetch_from_mcp` 替换为真实数据源调用即可；
- 企业微信告警接入点：`scripts/report_gen.py::_send_wecom_alert`。

### 5.2 新增业务指标
在对应技能包 `docs/inspection_standards.md` 表末尾追加一行，脚本零改动即生效。

### 5.3 目录结构（演示包）
```
比赛演示包/
├── run_demo.bat               # 一键启动脚本（流水线 + 控制台 + 验证 + 浏览器）
├── 比赛演示说明文档.md          # 本说明文档
└── skills/                    # 全部技能包与控制台（自包含，可独立拷贝运行）
    ├── equipment-inspection/  # ①设备点检技能包
    ├── quality-inspection/    # ②质量巡检技能包

    ├── process-optimization/  # ④工艺优化技能包
    ├── quality-traceability/  # ⑤质量追溯技能包

```
