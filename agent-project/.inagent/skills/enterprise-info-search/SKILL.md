# 企业调研信息检索

## 使用场景

- 学生提出"调研某家企业 / 查一下企业信息 / 这家公司是做什么的"。
- 串联流程的第一步：后续风险研判、横向对比、报告撰写都以此技能产出的《企业调研信息卡》为基础。

**前置输入（必须确认）**：目标企业名称（建议企业全称或统一社会信用代码）。
**若缺失**：明确告知学生"请提供要调研的企业名称（全称，例如：江苏xx智能装备有限公司）"，不得臆造企业数据。

## 执行流程

1. **输入校验**：确认企业名称准确、无歧义；如有同名企业，请学生补充地区/行业以消歧。
2. **信息检索**：围绕以下维度收集公开信息（企业官网、工商公示系统、企业信用信息公示系统、专利检索平台、新闻与行业报告等），标注来源与检索时间：
   - 工商注册信息：统一社会信用代码、注册资本、成立时间、登记状态、法定代表人、股东结构、经营范围。
   - 经营情况：主营业务、产品/服务、员工规模、营收/产值（如可获取）、出口情况、主要客户/市场。
   - 技术与知识产权：专利数量与类型、软件著作权、研发投入、高新技术企业资质、核心技术方向。
   - 资质与荣誉：认定的国家级/省级资质（专精特新、智能制造示范工厂、绿色工厂等）、行业荣誉、认证（ISO、CE 等）。
   - 行业地位：所在细分行业、区域集群定位、主要竞争对手（供后面对比使用）。
3. **信息整理**：去重、合并矛盾信息，无法核实处标注"待核实"。
4. **输出**：按下列结构整理《企业调研信息卡》。

## 输出

《企业调研信息卡》（Markdown 表格 + 分节说明）：

```
【企业调研信息卡】
- 企业名称 / 统一社会信用代码 / 注册地（江苏·xx市）
- 成立时间 / 注册资本 / 登记状态
- 法定代表人 / 股东结构（实际控制人）
- 主营业务与核心产品
- 所属行业与细分领域
- 经营规模（员工人数、营收等，标注来源与时间）
- 技术与知识产权（专利/软著/关键技术方向）
- 资质荣誉（专精特新、示范工厂、认证等）
- 行业地位与主要竞争对手
- 信息来源与检索时间
- 待核实项清单（如有）
```

- 所有数据标注来源与时间；未核实信息明确标记。
- 检索不到的信息不编造，列在"待核实项"中并给出获取渠道建议。
